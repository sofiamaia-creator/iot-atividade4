Enunciado: Lendo o sensor de presença
Em projetos de IoT, sensores e atuadores precisam ser integrados para que o sistema seja capaz de identificar eventos e executar ações automaticamente. Nesta atividade, você irá utilizar o Tinkercad para replicar um circuito de sensor de presença (PIR) e LED e, a partir dele, desenvolver o código de forma progressiva, implementando cada etapa até obter o funcionamento completo da solução.

## Materiais necessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 1 | Sensor PIR |
| 3 | Resistor de 1 kΩ |
| 1 | LED azul difuso de 5 mm |
| — | Fios de jumper macho-macho |
